# 글로벌 UI.UX 디자이너 영어 바이블 — 목차

## 1권 — 생활·업무 활용도와 시험 중요도에 따른 우선순위

### 01. [아이와 보낸 주말 이야기](1권/오늘의10문장.md#day-01-월요일-아침-동료와-커피-한-잔)

아이와 한 활동을 동료에게 짧게 설명.

- **생활·업무 활용:** 가족 일상과 출근 후 대화에 활용.
- **시험 연결:** Q5–7 · 질문에 직접 답하고 활동 설명.
- **본문 상태:** 본문 있음 · 개인화·회상 연습 적용.

### 02. [선호를 말하고 이유 붙이기](1권/오늘의10문장.md#day-02-점심-대화에서-선호와-의견-말하기)

점심 장소나 쉬는 방식을 고르고 이유 하나 말하기.

- **생활·업무 활용:** 작은 선택을 설명하는 대화에 활용.
- **시험 연결:** Q5–7, Q11 · 선호·입장과 이유 연결.
- **본문 상태:** 기존 본문 있음 · 새 형식 정제 예정.

### 03. [디자인 선택의 근거 설명하기](1권/오늘의10문장.md#day-03-디자인-선택의-근거-설명하기)

이 안을 선택한 이유와 사용자에게 생기는 효과 설명.

- **생활·업무 활용:** 시니어 디자이너의 리뷰·의사결정에 활용.
- **시험 연결:** Q11 · 입장과 근거를 연결하는 연습.
- **본문 상태:** 본문 있음 · 개인화·회상 연습 적용.

### 04. [평소 일과와 가족 시간 말하기](1권/오늘의10문장.md#day-04-평소-일과와-가족-시간-말하기)

평일에 하는 일과 주말에 하는 일을 간단히 설명.

- **생활·업무 활용:** 직업·육아 일상·근무 방식 대화에 활용.
- **시험 연결:** Q5–7 · 빈도·시점·구체적 활동 설명.
- **본문 상태:** 본문 있음 · 개인화·회상 연습 적용.

### 05. [업무 근황과 일정 조율](1권/오늘의10문장.md#day-05-업무-근황과-일정)

진행 상황, 마감, 바꿀 수 있는 시간 말하기.

- **생활·업무 활용:** 동료와 일정·작업 상태를 공유할 때 활용.
- **시험 연결:** Q5–7 · 계획 설명 / Q8–10 · 자료에 근거한 일정 전달.
- **본문 상태:** 기존 본문 있음 · 새 형식 정제 예정.

### 06. 못 들었을 때 확인하고 도움 요청하기

다시 말해 달라고 하거나 필요한 도움을 구체적으로 요청.

- **생활·업무 활용:** 회의에서 이해가 끊겼을 때 바로 활용.
- **시험 연결:** 시험 직접 전이는 제한적 · 녹음형 시험에 재질문하는 전략으로 사용하지 않음.
- **본문 상태:** 새 챕터 작성 예정.

### 07. 두 대안을 비교하고 제안하기

장단점을 비교한 뒤 더 적합한 안을 제안.

- **생활·업무 활용:** 디자인 선택·식사·근무 방식 결정에 활용.
- **시험 연결:** Q5–7, Q11 · 비교와 선택의 이유.
- **본문 상태:** 새 챕터 작성 예정.

### 08. 눈앞의 사람·행동·위치 설명하기

사무실이나 공원에서 보이는 장면 설명.

- **생활·업무 활용:** 위치 안내와 주변 상황 묘사에 활용.
- **시험 연결:** Q3–4 · 사진에 실제 보이는 정보로 묘사.
- **본문 상태:** 새 챕터 작성 예정 · 사진 자료 필요.

### 09. 일정표에서 시간·장소 찾아 전달하기

주어진 표에서 필요한 일정만 정확하게 전달.

- **생활·업무 활용:** 업무 일정이나 행사 정보를 안내할 때 활용.
- **시험 연결:** Q8–10 · 제공 정보 확인과 전달.
- **본문 상태:** 새 챕터 작성 예정 · 일정 자료 필요.

### 10. 짧은 공지 읽고 핵심을 전달하기

일정·장소·주의사항을 의미 단위로 끊어 읽기.

- **생활·업무 활용:** 공지·회의 안내를 읽어 전달할 때 활용.
- **시험 연결:** Q1–2 · 발음·강세·억양.
- **본문 상태:** 새 챕터 작성 예정 · 읽기 지문 필요.

### 11. 정중하게 반대하고 대안 말하기

상대 의견을 확인하고 다른 안의 이유 설명.

- **생활·업무 활용:** 리뷰·PM·개발자와 의견 차이를 조율할 때 활용.
- **시험 연결:** Q11 · 입장과 반대 근거를 정리하는 연습.
- **본문 상태:** 새 챕터 작성 예정.

### 12. 가족 일정과 업무 경계 말하기

가능한 시간·어려운 시간과 다른 제안 전달.

- **생활·업무 활용:** 가족 일정을 과도하게 공개하지 않고 약속 조율.
- **시험 연결:** Q5–7 · 일정과 선호 설명에 활용.
- **본문 상태:** 새 챕터 작성 예정.

### 13. 피드백을 구체화하고 다음 행동 정하기

무엇을 바꿀지, 이유와 후속 행동을 설명.

- **생활·업무 활용:** 시니어 디자이너의 리뷰·협업에 활용.
- **시험 연결:** Q11 · 구체적 예와 결과 연결 · 전문 표현 자체가 가점은 아님.
- **본문 상태:** 새 챕터 작성 예정.

### 14. 변경된 정보와 오해 정정하기

기존 일정과 새 일정을 구분하고 잘못된 정보 수정.

- **생활·업무 활용:** 일정 변경·회의 내용 확인에 활용.
- **시험 연결:** Q8–10 · 자료에 명시된 정보로 정정.
- **본문 상태:** 새 챕터 작성 예정 · 변경 정보 자료 필요.

### 15. 사진을 순서 있게 묘사하기

중심 장면에서 주변 정보로 이어서 설명.

- **생활·업무 활용:** 주변 상황을 차례대로 전달하는 연습.
- **시험 연결:** Q3–4 · 묘사의 연결성과 정확성.
- **본문 상태:** 새 챕터 작성 예정 · 사진 자료 필요.

### 16. 의견에 구체적인 경험 덧붙이기

입장·이유·내 경험·결과를 연결해서 말하기.

- **생활·업무 활용:** 리뷰에서 판단의 근거를 충분히 설명할 때 활용.
- **시험 연결:** Q11 · 준비와 제한 시간에 맞춰 의견 전개.
- **본문 상태:** 새 챕터 작성 예정.

### 17. 발표와 공지에서 중요한 부분 강조하기

핵심어·숫자·전환 지점을 알아듣기 쉽게 읽기.

- **생활·업무 활용:** 발표·업무 공지에 활용.
- **시험 연결:** Q1–2 · 강세와 억양 / 다른 답변에도 전달력 적용.
- **본문 상태:** 새 챕터 작성 예정.

### 18. 새 도구와 일하는 방식 평가하기

직접 써본 경험과 장단점을 설명.

- **생활·업무 활용:** 디자인 도구·협업 방식에 관한 대화에 활용.
- **시험 연결:** Q5–7, Q11 · 경험·비교·이유 재사용.
- **본문 상태:** 새 챕터 작성 예정.

### 19. 배운 상황 섞어서 답하기

같은 경험을 질문에 맞춰 짧게 또는 길게 말하기.

- **생활·업무 활용:** 실제 대화에서 주제가 바뀔 때 대응.
- **시험 연결:** Q1–11 · 과제 구분과 기존 표현 재사용.
- **본문 상태:** 복습 세트 작성 예정.

### 20. 모의 말하기와 막힌 부분 확인

유형별 질문에 답하고 필요한 표현만 다시 확인.

- **생활·업무 활용:** 본인이 자주 쓰는 상황부터 보완.
- **시험 연결:** Q1–11 · 준비·답변 시간에 맞춘 통합 연습.
- **본문 상태:** 모의 세트 작성 예정.

<details><summary>우선순위를 정한 기준</summary>
<p>생활·업무 활용도는 세 살 아이를 키우는 시니어 UI/UX 디자이너라는 상황에 맞춘 편집 판단이다. 실제 대화의 측정 빈도나 출제 확률 순위는 아니다.</p>
<p>시험 중요도는 문항별 과제와 다른 답변으로 옮겨 쓸 수 있는 범위로 판단했다. 이유 설명·비교·정보 전달을 앞에 두고, 첫 10개 챕터 안에 모든 시험 유형을 포함했다. 단순 문항 수를 점수 비중으로 환산하지 않았다.</p>
<p>챕터 번호는 추천 우선순위다. 앞 챕터 완료를 다음 챕터의 조건으로 두지 않는다. 사진·일정표처럼 자료가 필요한 과제는 해당 자료와 함께 연습한다.</p>
<p>문법은 각 상황의 문장을 설명할 때 필요한 만큼 다룬다. 과거형은 주말 이야기에서, 비교급은 대안 선택에서, 조동사는 요청과 제안에서 확인한다. 별도의 시제 단원을 먼저 끝낼 필요는 없다.</p>
<p>공식 평가에는 발음·강세·억양 외에 문법·어휘·연결성, 과제에 따른 내용의 관련성·완결성이 포함된다. <a href="https://www.iibc-global.org/english/toeic/test/speaking/about/format.html">IIBC 공식 시험 구성과 평가 기준</a>. 위 순서는 교재의 학습 제안이며 공식 권장 학습 순서는 아니다.</p>
</details>
